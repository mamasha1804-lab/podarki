# Подарки для ребят

Новогодняя игра для изучения английских слов. Автор: Лариса Коротаева.

Откройте `index.html` в современном браузере. Для локального запуска через сервер: `python -m http.server 8000`, затем откройте http://localhost:8000.

Управление: пальцем, мышью или стрелками. Поймайте английский перевод русского слова. Ошибка начинает игру заново. После сбора всех 28 подарков Дед Мороз машет рукой, садится в сани и улетает под инструментальную Jingle Bells.

В папке `assets` находятся все изображения и музыка. Установка зависимостей и сборка не требуются.
